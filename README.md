## 🚀 Quick Start

### Prerequisites

- **Node.js** 18+ and npm/yarn/pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/Aynaabaj/IELTS-1200-Words-Practice.git

# Navigate to project directory
cd IELTS-1200-Words-Practice

# Install dependencies
npm install

# Start development server
npm run dev
```

The app will be available at `http://localhost:5173`

## 📚 About IELTS 1200 Words

This application helps IELTS test-takers master the **1200 most frequently used words** in the IELTS Listening test. These words are essential for achieving a high band score.

### Why These 1200 Words?

- ✅ Based on actual IELTS Listening test analysis
- ✅ High-frequency words that appear repeatedly
- ✅ Essential for understanding context and questions
- ✅ Covers academic and general training topics

### Perfect For:

- 🎓 IELTS test preparation
- 📝 Academic English improvement
- 🌍 ESL/EFL learners
- 👨‍🎓 Students preparing for university
- 💼 Professional English development
